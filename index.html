    Tentang PPLG

    Apa itu Jurusan PPLG?

    Pengembangan Perangkat Lunak dan Gim (PPLG) bukan sekadar belajar ngetik kode. Di sini, kamu diajarkan untuk memecahkan masalah, merancang logika, dan menciptakan inovasi.

    Mulai dari website, aplikasi mobile, AI, hingga pembuatan Video Game. Di era digital saat ini, keahlian software development adalah "Superpower" yang sangat dibutuhkan oleh setiap perusahaan di seluruh dunia.

    Peluang Karier

    Mau Jadi Apa Setelah Lulus?

    Frontend Developer

    Spesialis pembuat tampilan website yang interaktif, responsif, dan memanjakan mata pengguna.

    Backend Developer

    Arsitek sistem di balik layar. Mengatur database, server, keamanan, dan logika aplikasi.

    Fullstack Developer

    Menguasai Frontend sekaligus Backend. "One-man army" yang sangat diincar startup & corporate.

    Game Developer

    Merancang alur cerita, karakter, dan memprogram game untuk PC, Console, maupun Mobile.

    Mobile Developer

    Membuat aplikasi canggih untuk Android dan iOS menggunakan teknologi modern seperti Flutter/React Native.

    Cyber Security

    Menganalisis celah keamanan website dan aplikasi untuk melindunginya dari serangan hacker.

    Kenapa Harus
    Pilih PPLG?

    Dunia bergerak ke arah digital. Mereka yang menguasai kode adalah mereka yang akan memimpin masa depan.

    KELAS 10

    Pondasi Dasar & Logika

    Pengenalan algoritma dasar, flowchart, dan logika pemrograman. Mempelajari dasar-dasar bahasa Java dan C, serta pengenalan pembuatan game menggunakan Godot Engine.

    Interaktivitas & Database

    Belajar JavaScript, PHP, MySQL. Mulai membuat website dinamis yang bisa menyimpan data. Belajar UI/UX menggunakan Figma.

    Framework & Game / Project Akhir

    Pengenalan Framework (Laravel/React). Kolaborasi tim dengan Git. Ujian Kompetensi Keahlian (UKK), dan pembuatan Game/Software siap pakai.
